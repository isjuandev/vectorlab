# VectorLab · frontend

Interfaz Next.js 16 / React 19 / TypeScript estricto / Tailwind 4 / shadcn/ui (Base UI).
Consulte el [README principal](../README.md) para instalación, arranque y pruebas.

| Comando | Qué hace |
| --- | --- |
| `npm run dev` | Servidor de desarrollo en `http://localhost:3000` |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run lint` | ESLint |
| `npm test` | Vitest (unitarias y componentes, jsdom) |
| `npm run test:e2e` | Playwright contra los servicios reales (los arranca si no están en marcha) |
